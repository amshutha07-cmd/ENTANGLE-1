## Independent Claim 1

"A hardware-instantiated erasure coding apparatus comprising:

a split-authority codec instantiation engine wherein a first commitment
value C₁, derived exclusively from a first hardware-rooted physical
source, determines the algebraic field structure of a Reed-Solomon
erasure code by selecting a primitive polynomial over a finite field,
and a second commitment value C₂, derived exclusively from a second
hardware-rooted physical source independent of the first, determines the
evaluation geometry of said Reed-Solomon code by selecting N distinct
nonzero evaluation coordinates within said field;

wherein C₁ and C₂ are each derived from physically separate hardware
sources using independent cryptographic derivation processes;

wherein neither C₁ alone nor C₂ alone is sufficient to instantiate the
complete Reed-Solomon code;

wherein an entity possessing C₁ without C₂ instantiates the correct
field structure without being able to determine the evaluation
coordinates required to construct the corresponding Vandermonde matrix;

wherein an entity possessing C₂ without C₁ determines coordinate values
without the field structure required to interpret those coordinates as
evaluation points of the complete Reed-Solomon code;

and wherein a residual polynomial R(x) computed over received symbols
following Reed-Solomon reconstruction, upon being non-zero, causes the
apparatus to reject the reconstructed data and output a hardware mismatch
indication, providing hardware attestation without stored key material,
key transmission, or key derivation from the codeword."

## Dependent Claim 2 — NFC Silicon Attestation

"The apparatus of Claim 1, wherein the first hardware-rooted physical
source comprises an NFC integrated circuit bearing a manufacturer-issued
cryptographic originality signature stored in read-only memory, verifiable
against the manufacturer's published elliptic curve public key over the
circuit's factory-burned unique identifier, such that any circuit unable
to present a valid originality signature is rejected before codec
instantiation."

## Dependent Claim 3 — Physical Immutability

"The apparatus of Claim 1, wherein C₁ is written to memory pages of the
first hardware-rooted physical source during a one-time provisioning
operation, said pages being subsequently write-locked by irreversible
one-time-programmable lock bits, rendering C₁ physically immutable after
provisioning without destruction of the physical device."

## Dependent Claim 4 — UID-Bound Polynomial Selection

"The apparatus of Claim 1, wherein primitive polynomial selection applies
a deterministic card-specific mapping derived from both C₁ and the
factory-burned unique identifier of the first hardware-rooted physical
source, such that two distinct physical devices presenting identical C₁
values instantiate different primitive polynomials."

## Dependent Claim 5 — Co-Presence Protocol

"The apparatus of Claim 1, wherein C₂ is derived from a freshness-bound
co-presence protocol wherein a fresh cryptographic challenge is bound to
the factory-burned unique identifier of the first hardware-rooted
physical source within an attestation response generated by the second
hardware-rooted physical source, such that C₂ is cryptographically bound
to the simultaneous physical presence of both hardware sources at
provisioning time and prior attestation responses cannot be replayed."

## Dependent Claim 6 — Hardware-Derived Code Rate

"The apparatus of Claim 1, wherein the number of evaluation coordinates N
is determined exclusively by C₁ via a domain-separated derivation
function, such that the code rate of the Reed-Solomon codec is a
deterministic function of the provisioned first hardware source."

## Dependent Claim 7 — Domain-Separated Derivations

"The apparatus of Claim 1, wherein field structure, code rate, and
evaluation geometry are each derived using domain-separated pseudorandom

domain-separated pseudorandom outputs from their respective

### Specification — Collision Probability Analysis

Under the following explicitly stated assumptions:

```
1. Polynomial selection is uniform over the set of primitive
   polynomials of the relevant degree over GF(2)
2. Coordinate selection is uniform over all possible subsets of
   the appropriate size from nonzero field elements
3. Evaluation coordinates are distinct nonzero field elements
4. C₁ and C₂ are modeled as statistically independent
5. Device pairs under comparison present non-identical commitment values
6. Derivation functions exhibit pseudorandom behavior
   indistinguishable from uniform random
```

For the specific instantiation over GF(2⁸) with N = 12 evaluation
coordinates:

The number of primitive polynomials of degree 8 over GF(2) is:

    φ(2⁸ − 1) / 8 = φ(255) / 8 = 128 / 8 = 16

The joint probability of primitive polynomial collision and evaluation
coordinate collision for any device pair presenting non-identical
commitment values is bounded by:

    P = 1 / (16 × C(255, 12)) ≈ 2⁻⁷⁰·⁷²

This probability bound is a mathematical consequence of the apparatus
structure under the stated assumptions and is not claimed as an
independent limitation.

### Specification — Distinction From Prior Configurable Codec Implementations

Unlike prior programmable Reed-Solomon implementations wherein codec
parameters are selected by software configuration at runtime (see e.g.,
US6385751B1), the present apparatus derives all codec parameters
exclusively from physically non-replicable hardware measurements
obtained from specific physical devices. The apparatus cannot be
instantiated on a general purpose computer without the specific physical
hardware components, and the codec parameters are not modifiable by
software executing at any privilege level.

---

### Specification — Section 3(k) Indian Patents Act Defense

The following statements support the apparatus classification of the
invention against potential Section 3(k) objections:

**Physical Irreversibility:**
The provisioning operation produces a permanent and irreversible physical
state change in the first hardware-rooted physical source's memory. This
physical irreversibility is not a software property and cannot be
simulated or reversed by any software operation. Destruction of the
physical device is the only means of altering the provisioned commitment
value.

**Hardware Non-Replicability:**
The codec parameters are derived from physically non-replicable hardware
sources whose outputs cannot be reproduced by software simulation. The
mathematical operations performed by the apparatus are inseparable from
and contingent upon the specific physical hardware configuration present
at both provisioning and reconstruction.

**Technical Problem Statement:**
Prior hardware authentication schemes derive cryptographic keys from
hardware state and use those keys to control access to a fixed
Reed-Solomon codec. An attacker who compromises the key gains complete
reconstruction capability. The present invention eliminates the key
entirely. The algebraic structure required for reconstruction does not
exist independently of the physical hardware. There is no key to
compromise, intercept, or replay.

> **algebraic structure of the codec itself** (field + geometry),
